This is a web application built on Python (Django) that helps manage tasks within an IT team.
The project implements a system for developers, designers, managers, and QA specialists, where each user can:

    * create tasks and assign them to other team members;

    * set deadlines, priorities, and task types;

    * track completed and uncompleted tasks;

    * mark tasks as completed.

The system supports user positions, task types, tags, teams, and projects, which allows you to effectively organize the company's work.

⚙️ Main features:

    * User management (registration, authorization, positions);

    * CRUD operations for tasks (create, edit, delete, view);

    * Assign performers (Many-to-Many relationship between tasks and employees);

    * Tag system for quick task search;

    * Support for teams (Teams) and projects (Projects) — different teams can work on different projects.
